# 🚀 AION Workspace

Unicron Workspace is an AI-powered productivity platform that combines conversational AI, artifact generation, workspace management, and analytics into a unified modern web application.

## ✨ Features

* 🤖 AI-powered chat interface
* 📄 Artifact generation and management
* 📊 Analytics dashboard
* 🗂️ Workspace organization
* 📜 Activity tracking and history
* 🎨 Modern UI with smooth animations
* 📱 Responsive design
* ⚡ Built with Next.js and TypeScript

## 🛠️ Tech Stack

### Frontend

* Next.js 16
* React
* TypeScript
* Tailwind CSS
* Framer Motion
* shadcn/ui
* Lucide Icons

### Development Tools

* npm
* Git & GitHub

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Unicron-2012/unicron-workspace.git
cd unicron-workspace
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
